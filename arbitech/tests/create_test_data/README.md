# Test Data Directory

This directory contains realistic test data for arbitrage detection testing, including:

## Directory Structure

- `betting_interfaces/` - Mock betting interface screenshots and images
- `market_data/` - Realistic market data samples with known arbitrage opportunities
- `bookmaker_odds/` - Multiple bookmaker odds datasets for different sports
- `scenarios/` - Pre-defined test scenarios with expected results
- `stress_test_data/` - High-frequency market data for stress testing

## Usage

This test data is used by the comprehensive testing framework to validate:
- Arbitrage detection accuracy
- Mathematical calculation precision
- Data aggregation functionality
- Performance under various market conditions

## Data Sources

All data is generated to reflect real betting market conditions while ensuring:
- Realistic odds ranges and relationships
- Known arbitrage opportunities for validation
- Edge cases and boundary conditions
- Performance scenarios for scalability testing
